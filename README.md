## Projects

### SumiFrame

A lightweight browser-based manga and storyboard editor built with HTML, CSS, JavaScript, and the Canvas API.

Features include:

- Drawing and erasing
- Text placement
- Multiple pages and panels
- Panel and page management
- Project save/load
- Live page preview
- PNG export

Live Demo: https://sumiframe.vercel.app/

GitHub: https://github.com/madeinmemory/sumiframe

Built with HTML, CSS, and JavaScript.
